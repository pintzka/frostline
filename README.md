# Frostline

Et 3D ski-triks-spill i nettleseren, laget av Daniel med hjelp fra Claude.

## Kom i gang
```
npm install
npm run dev
```
Åpne http://localhost:5173. Styr med ← → eller A D, brems med ↓ eller S, start på nytt med R.

## Sjekk før pull request
```
npm run check
```

Se `CLAUDE.md` for regler, `docs/DESIGN.md` for måltall og `ASSETS.md` for lisenser.
