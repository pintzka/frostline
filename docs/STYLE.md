# Frostline: visuell stil (utkast til godkjenning)

Forslag. Daniel og Carl godkjenner før fase 3 starter.

- **Stil:** ren, stilisert 3D. Lys og klar, ikke fotorealistisk. Myke farger, skarpe silhuetter.
- **Lys:** sol lavt på himmelen (sen ettermiddag), lange skygger, blå skygger i snøen.
- **Snø:** hvit med lett blåtone, svakt glitter, spor etter skiene.
- **Farger:** dyp blå himmel, hvit snø, varme aksenter (oransje/rød) på skiløper, rails og skilt.
- **UI:** stor, tydelig skrift (åpen font fra Google Fonts), få elementer på skjermen, triksnavn som popper opp og blir borte.
- **Referanser:** egne skisser og ekte bilder fra skiparker. Ikke skjermbilder fra andre spill.
